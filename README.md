# 729 (and counting)

729 (and counting) women and girls in the U.S. allegedly lost their lives to femicide in 2024. Based on the meticulous data collected by Dawn Wilcox from [Women Count USA](https://womencountusa.org/the-databases), this interactive visualization shows each life represented as a unique flower, marking their individuality and absence.

An effort in Data + Emotion, to bring back humanity to a widely reductionist practice where human lives are reduced to numbers.

## Data Source

[Women Count USA: Femicide Accountability Project](https://womencountusa.org/the-databases) by Dawn Wilcox — a working database with entries for each woman in various stages of completion.
